# `apps/insights` — التحليلات والتوصيات

**الحالة:** ○ مؤجّل — يُفعَّل بمفتاح FEATURE_AI_INSIGHTS

## ما سيُبنى هنا

- المرحلة الأولى: قواعد إحصائية بسيطة تعمل من اليوم الأول
- تنبؤ بالعملاء المعرّضين للفقدان
- اقتراح قيمة المكافأة المثلى
- AiInsight — نماذج تعلّم آلي بعد تراكم البيانات

## الملفات المتوقّعة

```
insights/
├── models.py         النماذج والهجرات
├── serializers.py    تحويل البيانات
├── views.py          نقاط API — استقبال وتحقق فقط
├── services.py       ◆ منطق الأعمال كله هنا
├── permissions.py    صلاحيات الأدوار
├── tasks.py          مهام Celery
├── admin.py          تسجيل في Django Admin
├── urls.py           مسارات التطبيق
└── tests/            اختبارات الوحدة والتكامل
```
