# `apps/loyalty` — نظام الولاء وقواعده

**الحالة:** ◆ ضمن النطاق

## ما سيُبنى هنا

- LoyaltyProgram — النماذج الستة
- ProgramRule — معدل المنح · السقوف · الصلاحية · سياسة العكس
- Reward — المكافأة وتكلفتها على التاجر
- Membership — عضوية العميل في علامة
- Balance — رصيد منفصل لكل علامة (لقطة محسوبة)
- قوالب القطاعات الستة الجاهزة

## الملفات المتوقّعة

```
loyalty/
├── models.py         النماذج والهجرات
├── serializers.py    تحويل البيانات
├── views.py          نقاط API — استقبال وتحقق فقط
├── services.py       ◆ منطق الأعمال كله هنا
├── permissions.py    صلاحيات الأدوار
├── tasks.py          مهام Celery
├── admin.py          تسجيل في Django Admin
├── urls.py           مسارات التطبيق
└── tests/            اختبارات الوحدة والتكامل
```
