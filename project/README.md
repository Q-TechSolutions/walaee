## البدء

```bash
cd project
cp .env.example .env       # ثم املأ القيم
make up                    # قاعدة البيانات و Redis
make help                  # كل الأوامر المتاحة
```

بعد إنشاء ملفات Django في مرحلة البناء:

```bash
make migrate
make seed
make test
```

**المنافذ المحلية:** PostgreSQL على `5433` و Redis على `6380` — مُزاحة عمدًا
تفاديًا للتعارض مع خدمات أخرى على الجهاز.

## قواعد ملزمة أثناء البناء

مأخوذة من التخطيط — كسرها يكلّف إعادة بناء:

1. **منطق الأعمال في `services.py` فقط** — الـView يستقبل ويتحقق ويستدعي الخدمة.
2. **الرصيد يُعدَّل من مكان واحد:** `apps/ledger/services.apply_entry()`.
3. **`LedgerEntry` بنمط append-only** — التصحيح بقيد عكسي لا بتعديل أو حذف.
4. **`select_for_update()` على الرصيد** — بدونه ضغطتان متزامنتان تمنحان النقاط مرتين.
5. **التسلسل الهرمي كامل من اليوم الأول** حتى لو لم يُستخدم.
6. **تغطية `apps/ledger` = ١٠٠٪** شرط للدمج، مع اختبار تزامن صريح.
7. **RTL كامل** ولا تباعد حروف على النص العربي.
8. **توكنات التصميم من مصدر واحد** — `frontend/shared/tokens/`.
