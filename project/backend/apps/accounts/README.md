# `apps/accounts` — المصادقة والهوية والصلاحيات

**الحالة:** ◆ ضمن النطاق

## ما سيُبنى هنا

- User — حسابات أصحاب المتاجر وفريق المنصة
- Customer — العميل النهائي بهوية واحدة عبر المنصة
- تسجيل الدخول بالهاتف + OTP وتحديد المعدل
- الموافقة على الخصوصية وتصدير البيانات وحذف الحساب
- إصدار توكنات JWT وإبطالها

## الملفات المتوقّعة

```
accounts/
├── models.py         النماذج والهجرات
├── serializers.py    تحويل البيانات
├── views.py          نقاط API — استقبال وتحقق فقط
├── services.py       ◆ منطق الأعمال كله هنا
├── permissions.py    صلاحيات الأدوار
├── tasks.py          مهام Celery
├── admin.py          تسجيل في Django Admin
├── urls.py           مسارات التطبيق
└── tests/            اختبارات الوحدة والتكامل
```
