## متطلبات تقنية

- **PWA:** Service Worker · manifest · تثبيت على الشاشة الرئيسية
- **قراءة QR** من كاميرا المتصفح مع معالجة رفض الإذن
- **Web Push** — القناة الافتراضية المجانية
- **يعمل دون اتصال** لعرض الرصيد المخزّن
