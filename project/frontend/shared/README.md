# `shared/` — المكتبة المشتركة

| المجلد | المحتوى |
|---|---|
| `ui/` | مكوّنات: أزرار · بطاقات · جداول · شارات · حالات فراغ وخطأ |
| `api-client/` | عميل مولّد من `/api/schema/` — لا يُكتب يدويًا |
| `tokens/` | ألوان · مسافات · خطوط · ظلال — مشتقّة من `docs/demo/assets/css/theme.css` |
| `utils/` | تنسيق العملة · التواريخ · الأرقام العربية · مساعدات RTL |

**قاعدة:** أي لون أو مسافة تُكتب مباشرة في تطبيق بدل التوكنات = مرفوضة في المراجعة.
