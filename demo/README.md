# ولائي — معرض الواجهات التفاعلي

نموذج عرض (Prototype) كامل لمنصة **walaee**، مبني مباشرة على مخرجات `Walaee_Analysis_Report_AR.pdf`.
كل شاشة هنا تجيب على مشكلة موثّقة برقمها في التقرير.

---

## كيف تشغّله

افتح `index.html` بأي متصفح — **مافيش سيرفر ولا تنصيب ولا إنترنت**.

```
demo/index.html            ← ابدأ من هنا
demo/present/index.html    ← العرض التقديمي مباشرة
```

> ملاحظة: خط Cairo يُحمّل من Google Fonts لو فيه إنترنت. من غير إنترنت بيقع على Segoe UI / Tahoma والشكل يفضل سليم.

## العرض التقديمي — `present/index.html`

١٨ شريحة بانتقالات ثلاثية الأبعاد، وفيها **واجهات المنتج الحقيقية مدمجة وحيّة** داخل إطارات هواتف ومتصفح.

### مفاتيح التحكم

| المفتاح | الوظيفة |
|---|---|
| `←` أو `مسافة` أو `↓` | الشريحة التالية |
| `→` أو `↑` | الشريحة السابقة |
| `O` | عرض كل الشرائح (Slide Sorter) |
| `F` | ملء الشاشة |
| `P` | تشغيل تلقائي (٨.٥ ثانية للشريحة) |
| `١` – `٩` | القفز لشريحة بالرقم |
| `Home` / `End` | الأولى / الأخيرة |
| `Esc` | إغلاق عرض الشرائح |

كمان: **عجلة الماوس** للتنقّل · **السحب باللمس** على الموبايل · **النقر على شريط التقدّم** للقفز ·
رابط مباشر لأي شريحة بالـ hash مثل `present/index.html#12`.

> للعرض الحقيقي: افتح الملف واضغط **F** فورًا لملء الشاشة. شريط التحكم بيختفي لوحده بعد ٣ ثواني سكون.

### ترتيب الشرائح

`١` الغلاف · `٢` المشكلة · `٣` السؤالان · `٤` الأطراف الثلاثة · `٥` تطبيق العميل (حي) ·
`٦` **آلية إثبات الشراء** · `٧` وضع الكاشير (حي) · `٨` نماذج الولاء الستة · `٩` لوحة التاجر (حي) ·
`١٠` الحوكمة · `١١` نموذج الأعمال · `١٢` الوحدة الاقتصادية · `١٣` التكلفة · `١٤` استراتيجية النمو ·
`١٥` خارطة الطريق · `١٦` المؤشرات · `١٧` هل تنجح؟ · `١٨` الخاتمة

---

### مسار عرض بديل للواجهات (٧ دقائق)

1. `index.html` — الافتتاحية وجدول تتبّع المشاكل
2. `customer/` → **«ابدأ من التسجيل»** — التسجيل في ١٥ ثانية
3. `customer/` → **«رحلة المسح والكسب»** — الرد على السؤال الأول لأي تاجر
4. `merchant/index.html#pos` — نفس الرحلة من جهة الكاشير
5. `merchant/index.html#fraud` — الحوكمة اللي بتفرّقك عن أي منافس
6. `admin/index.html#kpis` — الأرقام اللي بتقرر مصير المشروع
7. `plan/index.html` — الخطة والتكلفة والجدول الزمني

## تعديل البيانات المعروضة

كل الأرقام والأسماء في ملف واحد: **`assets/js/data.js`**.
غيّر اسم المتجر أو الأرقام أو الباقات وأعد تحميل الصفحة — من غير build ولا أدوات.

## النشر على Dokploy

ملفات Docker في **جذر المشروع** (خارج `demo/`):

```
walaee/
├── Dockerfile          nginx:alpine — يبني الصورة
├── nginx.conf          ضغط · كاش · رؤوس أمان · فحص صحي
├── docker-compose.yml  تعريف الخدمة لـ Dokploy
├── .dockerignore
└── DEPLOY.md           خطوات النشر كاملة ← اقرأه
```

تجربة محلية:

```bash
docker build -t walaee-demo .
docker run -d -p 8080:80 walaee-demo
# http://localhost:8080
```

الصورة ~٦٠ ميجابايت وتستهلك أقل من ٢٠ ميجابايت ذاكرة. التفاصيل في `DEPLOY.md`.

## تنبيه

البيانات كلها **تجريبية لأغراض التقديم فقط**. مفيش خلفية (backend) ولا قاعدة بيانات —
ده نموذج واجهات لتوضيح التجربة والقرارات، مش منتج شغّال.
