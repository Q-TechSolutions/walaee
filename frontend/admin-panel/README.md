# `admin-panel` — لوحة إدارة المنصة

**النموذج المرجعي:** `docs/demo/admin/` — ٧ شاشات.

| المجموعة | الشاشات |
|---|---|
| المنصة | نظرة عامة · مؤشرات الصحة |
| الإدارة | المتاجر · الاشتراكات والإيراد · المستخدمون |
| النظام | التشغيل والمراقبة · إعدادات المنصة |

## تفرقة مهمة

| | `frontend/admin-panel` | Django Admin |
|---|---|---|
| لمن | مالك المنصة وفريق الأعمال | الفريق التقني |
| المسار | `/admin` | `/django-admin` |
| المحتوى | الإيراد · المؤشرات · اعتماد المتاجر | جداول خام وتصحيح بيانات |

**`platform_admin` لا يرى بيانات شراء الأفراد** — قيد صلاحيات إلزامي.
