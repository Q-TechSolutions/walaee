# النطاق المعتمد

## ضمن النطاق — يُبنى الآن

| المكوّن | الموقع |
|---|---|
| تطبيق العميل PWA — ١٣ شاشة | `frontend/customer-pwa/` |
| لوحة صاحب المتجر — ١١ شاشة | `frontend/merchant-dashboard/` |
| لوحة إدارة المنصة — ٧ شاشات | `frontend/admin-panel/` |
| نماذج الولاء الستة | `backend/apps/loyalty/` |
| آلية إثبات الشراء | `backend/apps/pos/` |
| محرك القيود والرصيد | `backend/apps/ledger/` |
| كشف الاحتيال وسجل التدقيق | `backend/apps/fraud/` · `audit/` |
| التسلسل الهرمي والصلاحيات | `backend/apps/tenancy/` · `accounts/` |
| الحملات وموجّه القنوات | `backend/apps/campaigns/` |
| الاشتراكات والفوترة | `backend/apps/billing/` |

## خارج النطاق — تطوير مستقبلي

| المكوّن | السبب | السعر | التفعيل |
|---|---|---|---|
| الواجهات البرمجية العامة و Webhooks | لا تُستخدم قبل وجود شريك تكامل فعلي | ٢٢,٠٠٠ ج | `FEATURE_PUBLIC_API=1` |
| محرك التحليل والذكاء الاصطناعي | يحتاج ٦–١٢ شهرًا من بيانات حقيقية | ٤٣,٠٠٠ ج | `FEATURE_AI_INSIGHTS=1` |

المجلدان `backend/apps/publicapi/` و `backend/apps/insights/` **موجودان في الهيكلة**
حتى تكون البنية مُعدّة لاستقبالهما بلا إعادة بناء — لكن لا يُنفَّذ فيهما شيء الآن.

## غير مشمول إطلاقًا

- تطبيق سطح مكتب · Electron · تطبيق أصلي (iOS/Android) — **ويب فقط**
- رسائل SMS وواتساب (استهلاك فعلي يدفعه المالك للمزوّد)
- رسوم بوابة الدفع · تسجيل العلامة التجارية · المراجعة القانونية
- حملات التسويق وضم المتاجر الميداني
